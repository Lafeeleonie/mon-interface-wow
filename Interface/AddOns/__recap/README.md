## Note sur les modules

Les éléments listés après « Composants installés » sont des modules, bibliothèques, packs vocaux ou bases de données nécessaires à leur addon principal. Ils sont tout de même recensés pour couvrir l’intégralité des dossiers présents.

Raider.IO et toutes ses bases régionales sont volontairement regroupés dans une seule entrée.
